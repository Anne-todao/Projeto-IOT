Sobre o Projeto

O projeto consiste em um sistema de monitoramento ambiental das condições do ar e clima em tempo real utilizando a placa ESP32 Dev Module. A aplicação faz a coleta contínua de parâmetros ambientais, aciona indicadores visuais de alerta localmente e transmite os dados coletados via protocolo MQTT para um broker local.
